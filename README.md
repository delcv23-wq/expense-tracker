# 💰 Expense Tracker

A simple Expense Tracker application developed using Python, SQLite, and Gradio.

## 📌 Features

- Add daily expenses
- View all expenses
- Delete expenses
- Calculate total expenses
- Select expense categories
- Store expense data using SQLite

## 🛠️ Technologies Used

- Python
- SQLite
- Gradio
- Google Colab
- Pandas

## 🚀 How to Run

1. Open the `Expense_Tracker.ipynb` file in Google Colab.
2. Run the code cells step by step.
3. Launch the Gradio application.
4. Use the interface to add and manage expenses.

## 🎯 Project Objective

The main objective of this project is to provide a simple application for recording and managing personal daily expenses.
